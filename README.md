# MC_Сканер

Настольное приложение на Python и Tkinter для небольших компаний с мелким выпуском и торговлей. Оно упрощает три типовые операции с кодами «Честный знак»:

- собрать файл для выпуска продукции и загрузки на сайт Честного знака;
- собрать список кодов для отгрузки;
- проверить электронный УПД при получении товара: сверить коды из документа с кодами, считанными сканером с упаковки.

Для работы нужен 2D-сканер, который соответствует требованиям «Честного знака» и работает в режиме клавиатуры. Перед сканированием переключите раскладку на английский язык: в кодах есть латинские буквы, и при русской раскладке они запишутся неверно.


## Запуск

Нужен Python 3 и Windows (синтез речи и часть зависимостей рассчитаны на него).

```bat
Инсталл.bat
СТАРТ.bat
```

`СТАРТ.bat` запускает `pythonw main.py` без консоли. `ОТЛАДКА.bat` запускает `python main.py` и оставляет окно консоли.

Зависимости перечислены в `requirements.txt`: Pillow, requests, openpyxl, pyttsx3, reportlab, tkhtmlview.

## Меню

1. **Собрать новый файл выпуска продукции** — только полный код маркировки (SGTIN). Сохраняет `Нанесение_*.csv` и `Выпуск_*.xlsx` в `data/Выпуск`.
2. **Собрать новый файл csv** — SGTIN и SSCC в одном списке. Сохраняет `Сбор_*.csv` и `Сбор_*.xlsx` в `data/Сборка`.
3. **Загрузить и проверить файл** — сверка ранее сохранённого CSV со сканами. Строка должна совпасть целиком.
4. **Проверить поступление по УПД** — загрузка электронного УПД (XML `ON_NSCHFDOPPR`). В документе коды короткие (`01` + GTIN + `21` + серийный номер). Сканируется полный код с упаковки, сравнение идёт по GTIN и серийному номеру.
5. **Собрать коробки** — группировка кодов по коробкам, отдельный XLSX на каждую коробку в `data/Коробки`.
6. **Печать штрихкода гофроящика** — генерация SSCC и PDF с этикетками Code128 в `data/Штрихкода`.
7. **Нужна помощь** — справка из `assets/help.html`.
8. **Выход**.

Диалог сохранения открывается в соответствующей папке `data/…`. Папки создаются при первом обращении.

## Коды

Полный код маркировки:

- обязательно: GTIN (`01`), серийный номер (`21`), криптохвост (`92`, `93` или `94`);
- ключ проверки (`91`) необязателен: короткий формат с `93` часто идёт без него.

SSCC — 18 цифр либо `00` и 18 цифр.

Сканер может передать разделитель GS1 как текст `<GS>`. Программа заменяет его на символ GS (ASCII 29).

В XLSX для SGTIN пишется строка `01` + GTIN + `21` + серийный номер. В CSV пишется исходная отсканированная строка.

## Конфигурация

`config.ini`:

| Секция | Параметр | Назначение |
| --- | --- | --- |
| `SSCC` | `last_code`, `company_prefix`, `extension_digit` | Последний SSCC и префикс компании |
| `PRINT` | `label_width`, `label_height` | Настройки печати |
| `FEATURES` | `enable_chz` | `false` скрывает авторизацию и отправку в Честный знак |
| `UI` | `logo_path`, `logo_width` | Логотип. Высота считается по пропорциям картинки |
| `UI` | `help_path` | HTML-справка, по умолчанию `assets/help.html` |

## История

Проект начинался как внутренняя программа для Ultman — челябинского производителя профессиональной химии для ухода за оружием. Затем он был открыт и публикуется как MC_Сканер — открытое решение для небольших производств и торговли.
