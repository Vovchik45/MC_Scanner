Сборщик строк GS1

Краткая инструкция по работе с приложением

1. Назначение

Программа предназначена для сканирования и сбора кодов маркировки (SGTIN) и кодов коробок/паллет (SSCC), проверки файлов, формирования отчётов и печати штрихкодов гофроящиков.

Сканер обычно передаёт строку как клавиатурный ввод — достаточно установить курсор в поле ввода и отсканировать код.

2. Главное меню

  1. Собрать новый файл выпуска продукции — сбор кодов маркировки для нанесения и выпуска.
  2. Собрать новый файл csv — смешанный сбор SGTIN и SSCC (коробки/паллеты).
  3. Загрузить и проверить файл — сверка ранее сохранённого CSV со сканами.
  4. Проверить поступление по УПД — сверка электронного УПД со сканами полных кодов.
  5. Собрать коробки — группировка кодов по коробкам и выгрузка XLSX.
  6. Печать штрихкода гофроящика — генерация SSCC и PDF с этикетками.
  7. Нужна помощь — эта справка.
  8. Выход — закрытие программы.

3. Собрать новый файл выпуска продукции

Режим для полных кодов маркировки (SGTIN): AI 01, 21 и криптохвост 92 / 93 / 94 (ключ проверки 91 — если есть в коде).

Как работать

  1. Откройте пункт 1 и установите курсор в поле ввода.
  2. Сканируйте коды по одному (Enter / «Добавить строку»).
  3. Первый код задаёт ожидаемый GTIN — остальные должны совпадать.
  4. Дубликаты программа отклонит.
  5. При ошибке можно удалить последнюю / выбранную строку или включить режим удаления и просканировать код повторно.
  6. Нажмите «Завершить ввод» и подтвердите папку сохранения.

Результат

  • Нанесение_….csv — исходные строки кодов.
  • Выпуск_….xlsx — строки в формате 01+GTIN+21+SN.

Папка по умолчанию: data/Выпуск

4. Собрать новый файл csv

Режим для SGTIN и SSCC (18 цифр или с префиксом 00). Удобен, когда в одном файле нужны и единицы товара, и уже сформированные коробки/паллеты.

Как работать

  1. Откройте пункт 2.
  2. Сканируйте коды маркировки и/или SSCC коробок.
  3. Для SGTIN действует проверка единого GTIN; для SSCC проверка GTIN не нужна.
  4. В таблице виден тип строки: SGTIN или SSCC.
  5. «Завершить ввод» — сохранить файлы.

Результат

  • Сбор_….csv — все исходные строки.
  • Сбор_….xlsx — для SGTIN: 01+GTIN+21+SN, для SSCC: 18 цифр.

Папка по умолчанию: data/Сборка

5. Загрузить и проверить файл

  1. Откройте пункт 3 и выберите CSV с кодами.
  2. В таблице отобразится содержимое файла.
  3. Сканируйте коды для проверки — программа отмечает совпадения.
  4. Смотрите счётчики: всего / правильно / осталось.

6. Проверить поступление по УПД

Электронный УПД содержит коды в коротком виде: только GTIN (01) и серийный номер (21), без криптохвоста 92/93/94. Сканируйте полный код с упаковки — программа сравнивает его с УПД по GTIN и серийному номеру.

  1. Откройте пункт 4 и загрузите XML-файл УПД.
  2. В таблице появятся товар, артикул, GTIN и серийный номер из документа.
  3. Сканируйте коды маркировки с товара.
  4. Совпавший код отмечается «Найден». Код, которого нет в УПД, считается лишним.
  5. Смотрите счётчики: в документе / найдено / осталось / лишние.

7. Собрать коробки

  1. Откройте пункт 5.
  2. Сканируйте коды текущей коробки.
  3. Нажмите «Собрать коробку» и введите код коробки.
  4. Повторите для следующих коробок.
  5. «Завершить сборку» — выгрузить XLSX (отдельный файл на каждую коробку).

Папка по умолчанию: data/Коробки

8. Печать штрихкода гофроящика

  1. Откройте пункт 6.
  2. Укажите количество кодов, тип (коробка / паллета), при необходимости GS1-префикс.
  3. «Сгенерировать и показать предпросмотр» — список SSCC.
  4. «Сохранить в PDF» — этикетки со штрихкодами Code128.

Папка по умолчанию: data/Штрихкода

9. Полезные советы

  • Если сканер вставляет символ <GS> текстом — программа заменяет его на служебный разделитель GS1.
  • При достижении «круглых» количеств (10, 20, 30…) программа может озвучивать прогресс.
  • Папки data/… создаются автоматически рядом с программой.
  • В диалоге сохранения можно выбрать другую папку — стартовая будет соответствующей режиму.

10. Структура папок

  • data/Выпуск — выпуск продукции (пункт 1)
  • data/Сборка — смешанный CSV/SGTIN+SSCC (пункт 2)
  • data/Коробки — файлы коробок (пункт 5)
  • data/Штрихкода — PDF этикеток (пункт 6)
  • assets/help.html — этот файл справки
