# AGENTS.md

Инструкции для агента в проекте MC_Сканер. Это локальное Tkinter-приложение.

## Что не ломать

- Пункт 1 остаётся сбором только полного SGTIN и пишет два файла: `Нанесение_*.csv` и `Выпуск_*.xlsx`. Смешанный сбор SGTIN и SSCC — отдельное окно, пункт 2.
- Код Честного знака не удалять. Он выключен флагом `FEATURES.enable_chz` в `config.ini`. Клиент `TrueApiClient` создаётся только при `enable_chz = true`. Кнопки авторизации и отправки в `BoxCollectionWindow` не показывать, пока флаг выключен.
- Номера пунктов меню и тексты кнопок менять только вместе с `assets/help.html`.
- Пользовательский текст интерфейса и справки — на русском.

## Коды маркировки

Полный КМ (`StringCollectorApp.is_full_sgtin`): есть GTIN (`01`), серийный номер (`21`) и криптохвост (`92`, `93` или `94`). Поле `91` необязательно.

Короткий КИЗ из УПД: `01` + 14 цифр GTIN + `21` + серийный номер, без криптохвоста. Разбор УПД — `modules/upd_parser.py`. Сверка поступления сравнивает только GTIN и серийный номер через `simple_gs1_parse`, потому что скан полный, а строка в XML короткая.

SSCC: 18 цифр или префикс `00` и 18 цифр (`is_sscc` / `normalize_sscc`).

`<GS>` в тексте сканера заменяется на `chr(29)` методом `replace_gs`.

Для распознавания, от которого зависит приёмка кодов, вызывай `simple_gs1_parse`. `parse_gs1_string` сначала пробует пакет `gs1` и при любой ошибке возвращает пустой результат, а не запасной разбор.

## Окна и файлы

Каждое рабочее окно — `tk.Toplevel`. В `WM_DELETE_WINDOW` вызывать `app.show_main_window()` и `destroy()`. Главное окно перед открытием рабочего скрывается через `hide_main_window()`.

Новое окно: класс в `modules/`, импорт в `modules/windows.py` (`__all__`) и в `modules/app.py`, кнопка в `create_main_interface`.

Папки сохранения не хардкодить в окнах. Брать их из `app.get_export_dir()`, `get_assembly_dir()`, `get_boxes_dir()`, `get_data_dir()`. Каталоги `data/Выпуск`, `data/Сборка`, `data/Коробки`, `data/Штрихкода`.

УПД — XML в кодировке Windows-1251, формат `ON_NSCHFDOPPR` / КНД 1115131. `xml.etree` читает объявление кодировки сам. Имена тегов сравнивать без namespace (`_local` в `upd_parser.py`). Коды лежат в `СведТов / ДопСведТов / НомСредИдентТов / КИЗ`.

Логотип грузится с диска. Ширина — `UI.logo_width`, высота считается из пропорций файла. Не возвращать загрузку логотипа по HTTP.

Справка: править `assets/help.html`. `tkhtmlview` не переваривает полный документ и `<style>`; в виджет отдаётся только содержимое `<body>` (`HelpWindow._body_for_viewer`).

## Проверка

Автотестов нет. После изменений парсера прогоняй короткий сценарий на `simple_gs1_parse`: полный код с `92`, короткий код с `93` без `91`, SSCC из 18 цифр. Для УПД можно взять XML из `docs/` и проверить, что число `КИЗ` совпадает с числом распознанных пар GTIN и серийный номер.

Не запускай приложение в интерактивном цикле `mainloop` из агента: окно не закроется само. Импорт и разбор без `mainloop` достаточны.

В `docs/` лежит реальный пример УПД.
